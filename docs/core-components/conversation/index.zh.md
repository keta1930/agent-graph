# 对话

查看 Agent 回复和 Graph 结果，预览会话文件，并[分享](share.zh.md)或[导出](export.zh.md)对话。

## 会话图片 {#conversation-images}

使用支持视觉的模型讨论上传的图片。只有保存成功的图片才会附加到会话，未附加的图片可重新上传。同名图片再次上传时会单独保存，较早消息中的图片保持原样。配置方法见[多模态支持](../../roadmap/multimodal.zh.md)。

## 数学公式 {#mathematical-formulas}

以下 Markdown 展示区域支持行内和块级 LaTeX 数学公式：

- 聊天消息和展开的推理内容，包括流式回复、历史消息、任务会话和分享会话。
- Graph 最终结果。
- 会话 Markdown 文件预览，包括分屏模式。
- Prompt 编辑器预览和 Markdown 预览卡片。
- 内置工具分类说明。

工具参数和工具原始结果沿用其现有数据展示格式。

### 行内与块级语法

使用单个美元符号包裹行内公式，也可用在 Markdown 表格中：

```text
能量为 $E = mc^2$。
```

块级公式的前后两个双美元分隔符需要分别独占一行：

```text
$$
\frac{a}{b} = \sqrt{x}
$$
```

标记为 `math` 的围栏代码块也会渲染为块级公式：

````text
```math
\begin{pmatrix}
1 & 0 \\
0 & 1
\end{pmatrix}
```
````

在同一行写 `$$x^2$$` 会生成行内公式。

模型回复也可使用 `\(...\)` 包裹行内公式，使用 `\[...\]` 包裹块级公式：

```text
状态价值为 \(V^*(s)\)。

\[
V^*(s) = \max_a \sum_{s',r} p(s',r\mid s,a) [r + \gamma V^*(s')]
\]
```

块级公式从独立行开始，关闭符号 `\]` 后只能有空白。独立成行的 `\[x^2\]` 也支持；段落中间的 `文字 \[x\] 文字` 仍按普通 Markdown 显示。普通 `(x)` 和 `[x]` 不会被识别成公式。

在代码外展示字面分隔符时，将反斜杠写两次：`\\(x\\)` 和 `\\[x\\]`。公式内部的 `\\` 仍表示 TeX 换行，也支持 `\\[2pt]` 等行间距写法。

### 金额与代码

金额中的美元符号需要用反斜杠转义：

```text
价格分别为 \$5 和 \$10。
```

未转义且成对出现的美元符号可能被解释为公式。例如，`Costs $5 and $10` 可能将两个美元符号之间的内容按公式排版。`$2x$` 等表达式属于有效公式。

行内代码和普通围栏代码块会保留公式源码。例如，输入 `` `$x^2$` `` 会显示原始美元符号和表达式。展示源码时可使用 `text` 或编程语言围栏；`math` 围栏会渲染公式。

### 流式输出、错误与长公式

回复生成过程中，未完成的公式可能暂时显示为文本或部分排版的公式。尚未闭合的括号分隔符按 Markdown 显示，块级起始符附近的段距可能暂时变化；关闭分隔符到达后会更新为公式。非法或不受支持的公式会以可读的 TeX 形式显示，不会中断回复；内容修正后会重新渲染。

过长的行内和块级公式可在公式区域内横向滚动。窄屏下也可滚动该区域查看表达式的其余部分。
